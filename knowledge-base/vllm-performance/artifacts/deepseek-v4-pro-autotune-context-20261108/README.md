# DeepSeek-V4-Pro 寻优扩展知识采集

采集日期：2026-11-08（Asia/Shanghai）。本轮通过两台目标主机的指定容器只读采集，没有启动、停止或重启服务，没有推理请求、硬件打流或新性能实验。

## 已收集内容

- `scenario.json`：模型属性、当前双节点软硬件快照、历史负载组、基线资格与证据缺口。
- `startup-config.json`：非身份启动参数及性能环境变量，脚本与历史结果的精确哈希关联。
- `config.json`、`generation_config.json`、`tokenizer_config.json`：当前模型元数据，保留源字节；tokenizer 与权重索引哈希及索引统计在 scenario 中，未读取/哈希巨量权重分片。
- `source-provenance.json`：历史三组件版本、源哈希、当前来源及差异。
- `historical-protocol.json`：初始协议、修订、缓存覆盖改动及日志恢复证据，后续协议修订优先。
- `round-manifest.json` 与 `rounds/`：31 份已有逐轮快照，包括正式、额外预热和取消轮次；完整保留有限数值的 before/after/delta 指标。路径改成逻辑引用，原 raw_log 键改为 measurement_log_ref，原文件哈希与发布文件哈希分别保存。未重新运行这些轮次。
- `historical-runtime.json`：4 份历史服务日志的选定原行、源哈希、加载/KV/图捕获测量和有效配置。
- `implementation-evidence.json`：当前已安装代码的相关片段及完整源文件哈希；这是源码证据，不是运行验证。
- `relation-candidates.json`：MC2/多流与调度合法性源码规则、批量/序列/KV 和投机/图模式等待验证交互；没有宣称参数收益。
- `autotune-plan-draft.json`：默认关闭、未授权执行的计划草稿；未补猜阈值、预算或候选值。

## 时间与关联边界

两台当前容器的启动时间晚于 11 月 6 日的测试，故当前镜像/组件/硬件状态不自动回填到历史。但原测试目录仍保存 environment.json，可恢复当时 vLLM、vLLM-Ascend、AISBench 三组件版本。当前两份 AIV 脚本与历史 source_sha256 完全一致，共享目录内 7 份结果文件也与既有知识库逐字节相同。

当前 aisbench_test.py 和 config.py 与历史哈希不同，当前配置已指向其他模型；不能用当前工具配置填充历史生成设置。generate_dataset.py 和定向前缀副本的哈希可分别核对。历史 environment 是初始协议，protocol_revision 覆盖后续预热、复测和选点约定。

历史服务日志支持 DP8、TP1、PP1、PCP2、DCP1 及 EP rank 0–15 的合设配置；目录名不能作为 PD 分离证据。日志有 77.21 GiB 的模型加载分配、约 5.7 GiB 的可用 KV 与 0.72 GiB 的图捕获分配，具体逐 rank 值在证据文件。不同阶段不能相加冒充正式负载峰值，更不能仅凭这些数字断言瓶颈。

## 当前未通过的门槛

两台容器进程快照均未发现匹配的目标 vLLM CLI/engine；本轮未调用健康 HTTP 或推理请求，不宣称目标服务已就绪。两台设备均出现非 OK 健康状态，具体设备及状态保存在 scenario。此次没有开展告警诊断或修复。

不存在新目标环境的已验收性能基线；正确性/精度、长稳、峰值显存余量及延迟尾部均未重新验收。原始性能观察多数每点正式一次，不提供重复估计的置信区间。名义前缀比例、实际命中和初始覆盖继续分别表达。

模型元数据声明 fp8 量化配置与 fp4 专家 dtype，应分别保留；历史运行时日志解析为 deepseek_v4_fp8。当前元数据/索引/tokenizer 一致不证明历史权重分片未变。当前源码中的 Qwen 专有 DSpark 条件不能迁移成 DeepSeek 的已知约束。所选历史计数器未含投机接受率，缺失不等于零。

## 原始证据与后续使用

既有 case、26 条正式观察、CSV、曲线和修订快照不变；日志恢复的额外正式观察继续引用原归档。私密原始采集留在本机过程目录，不进入共享仓库。共享文件保留公开版本、配置和性能数值，删除认证材料与环境身份。

本目录是采集证据与候选知识，不是已实现的自动寻优器，也不授予启动或测试权限。跨场景使用时需给出来源修订、条件检查、迁移依据、反例和最小验证项。完整方案见相邻的 autotune-extension-design-20261108。
