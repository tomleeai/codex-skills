QSA reproduction and validation, original v0.32 RC deployment

Hardware/runtime: two nodes, eight Ascend 950DT NPUs per node; original image
sha256:ddc16dd6ba93a789bc836b6ce41049da552f3d25caac7f7e73dd8f79d74aed2a;
vLLM 5df63a7 (0.32.0), image Ascend 62fe4cde6, CANN 9.2.1,
torch 2.10.0 and torch_npu 2.10.0.post7. W4A8-MXFP checkpoint:
Qwen3.8-Flash-Next. Both endpoints use all eight cards, TP4/DP2/EP,
MRV2, language-model-only and MTP3. P uses eager; D uses FULL_DECODE_ONLY
and npugraph_ex with speculative enforce_eager=false.

Prerequisites: correct same-host HCCL topology information and the complete
compiled custom-op vendor artifacts from the same image. A source checkout
contains only source; linking its shared libraries alone is insufficient.

The adjacent run_p.sh, run_d.sh, env.sh and proxy.sh are sanitized copies of
the actual scripts. Only endpoint/NIC/checkpoint/profiler paths and identifying
comments were parameterized. Original script hashes are in script-provenance.json.
Bash syntax validation passed; the parameterized copies were not separately
executed as a new full experiment. Actual experiments used unchanged originals.

On the P node set MODEL_PATH, P_HOST and NIC_NAME; run bash run_p.sh.
On the D node set MODEL_PATH, D_HOST and NIC_NAME; run bash run_d.sh.
Launch both roles together. After both health endpoints are ready, set P_HOST
and D_HOST on P and run bash proxy.sh. Ports are P8247/D8248/proxy8246.

1. With the unmodified image source and original scripts, both roles fail
   raw-key view initialization: view=2048, region=2240.
2. Apply qsa-raw-stride.patch in the image Ascend source tree; keep the same
   scripts. P then reproduces the original fused norm+RoPE ABI warmup error.
3. Add the historical qsa-rope-fallback.patch: both roles finish warmup and
   complete short32 and exact 131072+1 requests through the proxy.
   This historical patch is distinct from the revised PR21979 implementation.
4. For the revised release PR, use PYTHONPATH pointing at ede5235c and apply
   qsa-raw-stride.patch as the independent prerequisite. Use image-matched
   complete runtime binaries/vendor artifacts. Run the same original scripts.
